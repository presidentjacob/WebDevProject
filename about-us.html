About Our Project

Collection Tracking Database - Web Development Semester Project

Our Project

This project is a collection tracking database designed to help users organize and keep track of anything they collect. Whether it’s books, trading cards, coins, games, or other items, users can add, update, and manage their collections in one simple system. This was built as part of our semester web development course.

About Us

This project was created by two students working together to design and build a functional web application. We focused on making the system simple, user-friendly, and useful for real-world collection tracking.
